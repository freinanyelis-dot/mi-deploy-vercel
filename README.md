# Práctica de despliegue web con Vercel

## Descripción del proyecto

Este proyecto consistió en una práctica introductoria para aprender a desplegar y publicar una página web utilizando **Vercel**, una plataforma que permite poner sitios web en línea y compartirlos mediante una URL pública.

El objetivo principal fue familiarizarse con el proceso de despliegue, desde disponer de los archivos del sitio hasta publicarlo y comprobar que estuviera accesible desde un navegador.

## ¿Qué es Vercel?

Vercel es una plataforma de despliegue web que facilita la publicación de proyectos en Internet. Permite conectar repositorios de GitHub y automatizar el despliegue cuando se realizan cambios en el código, según la configuración del proyecto.

Entre sus funcionalidades principales se encuentran:

- **Despliegue web:** publicar un proyecto para que pueda consultarse mediante un enlace.
- **Integración con GitHub:** conectar un repositorio para facilitar la publicación y actualización del sitio.
- **Despliegues automáticos:** generar nuevas versiones cuando se actualiza el repositorio conectado.
- **URL pública:** proporcionar una dirección web para acceder al proyecto.
- **Vista previa de cambios:** permitir la revisión de versiones antes de llevarlas a producción, según el flujo de trabajo configurado.

## Proceso realizado

Durante esta práctica se trabajó con el proceso básico de publicación de una página web:

1. **Preparación del proyecto:** se creó una página web sencilla como contenido inicial.
2. **Configuración del despliegue:** se utilizó Vercel para publicar el proyecto.
3. **Publicación:** se generó una versión accesible desde una dirección web.
4. **Verificación:** se comprobó que la página se pudiera abrir desde el navegador.

## Tecnologías y herramientas

- **Vercel:** plataforma utilizada para desplegar y publicar la página web.
- **GitHub:** repositorio para almacenar el código fuente, si se utilizó en el proceso.
- **HTML:** lenguaje utilizado para construir la estructura básica de la página.

## Aprendizajes obtenidos

- Comprender el propósito de una plataforma de despliegue como Vercel.
- Conocer el proceso básico para publicar una página web.
- Aprender cómo una página local puede convertirse en un sitio accesible mediante una URL pública.
- Familiarizarse con la relación entre el repositorio de código y la plataforma de despliegue.
- Identificar cómo se pueden actualizar y volver a publicar los cambios de un proyecto.
